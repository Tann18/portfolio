# Tanmay Das — AI Developer Portfolio

A clean, modern portfolio for **Tanmay Das** (AI Developer @ Interloom & Computer Science Engineering Student @ MIT Bengaluru).

Built to showcase production-grade AI systems, explainable machine learning models, and resilient agent architectures with interactive sandbox inspections and engineering post-mortems.

---

## Key Projects & Interactive Sandboxes

- **AI Developer @ Interloom**: Semantic ATS scoring engine using BAAI/bge-small embeddings, co-hyponym guardrails (sibling filter preventing false positives between related tools like Docker and Kubernetes), and conjunction groupings.
- **Autonomous Support Agent**: Mathematical confidence triage pipeline built with Python, n8n, and LLMs, featuring deterministic human-in-the-loop escalation.
- **Pneumonia Grad-CAM Visualizer**: Medical computer vision radiograph analyzer built with PyTorch and Grad-CAM, with an explainability mode demonstrating how "PORTABLE" marker data leakage was diagnosed and eliminated.
- **Autonomous Honeypot Deception System**: Decoy telemetry network trapping unauthorized SSH probes and command injection attempts with synthetic delay emulation.
- **SagarMitra – ORCA Platform**: Multi-agent maritime intelligence fusing ocean bathymetry, sea-surface temperature satellite feeds, and vessel route optimization during cyclonic weather fronts.
- **Things I Broke While Building Systems**: Candid engineering post-mortems detailing real incidents, root causes, and architectural principles forged.

## Tech Stack

- **Framework**: React 19

- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons
- **Language**: TypeScript

---

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
